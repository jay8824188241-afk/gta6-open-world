**Neon Bay** is an original 2D top-down open-world crime game, in the spirit of the classic era: steal cars and drive them across a living sunset city, outrun the Bay PD under a 5-star wanted system, fight gangsters and cops, and run four story missions for Mara Voss — from boosting your first ride at Ray's Paint Shop to a dockside shootout with the Vipers and a city-wide getaway. Traffic, pedestrians, a HUD with minimap, a title screen, localStorage saves and synthesized WebAudio sound are all in, and the whole game is plain HTML/CSS/JS with zero network requests: it plays offline in any desktop browser. Every name, character, map and sound is original.

## Run it

```sh
node serve.ts # then open http://localhost:8080
```
